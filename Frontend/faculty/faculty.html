Faculty Functions Roadmap

Suggested operations for Lecturers, HODs, and Deans, with how the system should support each.

Lecturer: Course Roster

View assigned units, student list, and registration status per class.

System support: class list APIs, enrollment snapshots, add/drop history.

Lecturer: Continuous Assessment

Create CATs/assignments and record marks with version history.

System support: assessment schema, draft/final states, audit trail.

Lecturer: Final Exam Grading

Capture final exam marks, compute totals, and apply grading scale.

System support: grading rules, moderation flagging, recalculation endpoints.

Lecturer: Attendance Tracking

Mark attendance by session and identify at-risk students.

System support: session records, percentage summaries, alerts.

Lecturer: Result Submission

Submit finalized marks to department for approval.

System support: submit/recall cycle, digital sign-off, deadlines.

HOD: Department Approval

Review course results, return for correction, or approve for dean review.

System support: workflow states, remarks, approval timestamps.

HOD: Workload Oversight

Track staff teaching loads and course coverage each semester.

System support: assignment matrix, conflict checks, workload reports.

Dean: School-Level Moderation

Monitor performance trends and ensure grading compliance across departments.

System support: cross-department analytics, grade distribution dashboards.

Dean: Publish Approved Results

Authorize release of approved results to students.

System support: publication window, freeze policy, notification trigger.
